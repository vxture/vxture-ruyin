## Microsoft 签名候选的验收顺序

1. 确认版本、签名和来源，备份当前数据并核对恢复条件。
2. 在隔离测试 Windows 用户或测试电脑安装；不覆盖用户当前工作环境。
3. 验证正常启动、只读安装目录、离线读取、SQLite、PDF 及受支持的工具启动。
4. 用合成项目验证登录、组织工作区、智能体安装、后台任务、重启恢复与导出。
5. 单独验证升级前后的数据和密钥一致性、旧版共存及回退限制。
6. 将成功结果与失败项绑定具体包哈希，再决定发布。只有所有必需条件满足才标记可交付。
