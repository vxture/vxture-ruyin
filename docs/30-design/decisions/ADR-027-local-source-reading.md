# ADR-027 本地原文读取与不可变快照

- 状态：P7.1 实施决定，2026-11-19；沿用负责人已授权的 P7 开发及本地登记权限。
- 范围：确定性的 PDF、DOCX、UTF-8 Markdown 结构读取，不做模型解析、OCR 或业务推断。
- 关联：ADR-008/013 的模型理解边界、ADR-018 本地工具分发、ADR-022 产品隔离；RY-102 待原件可访问时同步本轮接口补记。

## 决定

成熟解析库通过宿主受控、固定参数的本地读取适配器执行。输入仅为当前项目已导入且摘要核对过的文件，产品不能传入路径、脚本、命令或网络地址。连接器继续搬运字节，runtime-core 不依赖解析库。确定性结构读取不改变模型理解仍经网关执行的边界。

复用安装包已有 CPython；读取脚本及哈希锁定的 pdfplumber、python-docx 依赖在构建时准备到 `resources/document-reader`，许可证随依赖保留。运行时 `-I -B` 启动固定脚本，不安装依赖、不下载、不回退公网，不使用 Codex 或系统 PATH 中的 Python。开发观察台显式指定已安装 RUYIN 的 Python；与正式装配使用相同脚本和库。

本地文件输入限制 20 MiB，PDF 限 500 页，快照总量限 12 MiB、单块限 1 MiB。超限、加密、损坏、缺依赖和进程超时明确失败，不截断后冒充完整。图片、稀疏文字、合并表格和跨页边界保留提示。DOCX 不生成虚假 Word 页码。

## 保存与恢复

任务元数据、逐页/结构块与 Markdown 正文保存在现有项目加密文档库，使用只允许宿主写的 `runtime_` ID。文件 ID、SHA256、读取器版本和位置随快照保存；完成的快照不可修改。同一请求 ID 幂等、同一项目同时一个读取任务，daemon 单队列控制资源。页面只发起和查询，逐块进度随处理落盘。daemon 重启将未完成读取标为中断，已存块保留可查；重试创建新快照，不拼接两个版本。

产品侧选择文件、查看正文和异常。源文件区不可变，外部原件修改不会自动改已导入版本；用户重新导入后显示同名不同摘要版本，旧快照保留，不修改已确认矩阵、草稿或成果历史。

## Local API 增量（RY-102 本地补记）

仅产品级 bridge 凭据，project/product 从凭据取得，并检查活动 workspace 与项目可用状态：

- `POST /bridge/readings`：`{id: UUID, fileId: string, hash: SHA256}`，返回 202 与任务元数据；只读当前项目文件，忽略自由路径的方案不采用，额外字段拒绝。
- `GET /bridge/readings`：当前项目快照任务列表；包含状态、摘要、读取版本、块数、总页数及提示，不返回路径和原始二进制。
- `GET /bridge/readings/:id`：同一范围的任务与原件是否仍可用。
- `GET /bridge/readings/:id/units/:index`：指定已持久化块，包含 Markdown、来源位置、表格/图片区域与异常；index 从 0 开始。允许查询中断任务已完成的块，不表示读取已完成。

这使产品可以查看用户明确选择读取的派生正文，是 ADR-022 原先仅元数据面的受控扩展：不新增任意文件下载、路径访问或工具执行权限。正文仍是不可信资料，用安全 Markdown 渲染，不可当作指令。

P7.2 分批模型任务与 P7.3 引文核验未包含在本决定的交付结论中。
