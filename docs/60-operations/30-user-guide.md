# RUYIN 桌面端使用指南

适用候选：0.2.1-beta.1。商店认证、实际安装验收状态见
[交付状态](../50-deployment/100-beta-021.md)。

## 登录与工作区

启动后点击登录，在浏览器的 Accounts 页面完成身份认证，再返回桌面端。
账号菜单中的“组织切换”用于选择已加入的组织及其工作区。切换使用已有登录身份，
由平台重新校验目标工作区权限；平台未提供对应能力时会提示不可用。不要通过
清空本机数据解决工作区切换问题。

首页展示当前工作区可用的智能体。订阅权益、在线入口与本机安装分别判断：
订阅成功不等于本机已安装；只有提供在线入口的产品才显示在线使用。
尚无智能体时，可从应用中心选择产品。

## 安装与更新智能体

从左侧“智能体”进入管理页，或使用首页的安装入口；两处读取相同的安装记录。
选择 `.ruyinpkg` 后先检查兼容性、完整性、发布者签名、产品契约与资源边界，再确认安装。
无法校验的包不应通过关闭验证安装。正式签名与信任配置的交付条件见
[智能体包交付](../50-deployment/110-agent-packages.md)。

新版本独立保存，启用后使用新版本；保留的旧版本可用于回滚。
回滚程序版本不能撤销新版本已经写入的业务数据，操作前先备份。
卸载智能体版本保留项目资料；保留资料需要可兼容的智能体才能继续使用。

RUYIN 软件更新与智能体更新独立。更新智能体无需重装工作台。
只支持浏览器的产品使用在线入口，不显示为待安装的桌面程序。

## 执行任务与后台运行

任务由智能体提交给运行环境。离开页面不会取消后台任务，返回时读取已保存的状态和结果。
需要资料授权、人工确认或服务恢复时，查看任务提示后继续。

“设置 → 通用 → 关闭窗口”可选择后台运行或退出应用。后台运行时窗口隐藏到系统托盘，
任务继续；从托盘可重新打开或退出。完全退出、关机或休眠期间不能继续本机计算。
重启后的恢复取决于智能体保存的任务进度及外部服务，不承诺所有操作自动重试。

## 标书编写

一次投标建立一个项目，按六个环节推进：

1. **招标解读**：导入文件，智能体提取商务与技术要求并保留依据。
2. **需求确认**：核对、补充并确认需求矩阵。发现疑点时，操作人员可记录澄清、选择和说明，
   也可决定向采购方或代理询问；不要求等到外部答复才进入下一步。
3. **编写规划**：设置页数、配图、编写模式、质量与分册范围，生成目录及分批任务计划，确认目录。
4. **标书编写**：按章节分批生成并合稿；可独立重写某章。更改需求或资料后留意已有结果的失效提示。
5. **审核修订**：检查需求覆盖、依据及企业资料，审阅智能体建议并修订。
6. **成果导出**：选择用户导入的模板，试排后导出 Markdown、DOCX 或 PDF。

Markdown 是内容源；Word 负责试排与最终输出。没有可用 Word 排版环境时，
不能把浏览器内容预览当作最终 Word 页面的验收。资质、人员、产品和方案资料
通过知识资料管理使用，版本变化需要重新检查引用。

## 备份与恢复

在“设置 → 通用”中选择备份位置并按提示重启。备份前运行环境需要停止写入；
系统核验文件、密钥及数据库后才报告成功。不要在备份过程中移动、同步替换或编辑数据目录。

恢复选择一个新的空目标目录，原数据和备份保留。恢复会带回备份中的账号与本地设置，
外部授权文件夹的文件不包含在运行环境备份中，需要单独保管。
Windows 密钥受当前用户及电脑保护；当前备份不能作为跨电脑迁移方案。
丢失原主密钥或项目密钥时，仅有数据库文件不足以恢复。

## 诊断与隐私

遇到问题先查看任务错误及服务状态，再使用设置中的诊断功能。
诊断由用户主动运行、下载，不自动上传；摘要排除凭据、项目正文及原始日志。
联系支持时附应用版本、发生时间、操作步骤和诊断摘要即可，不发送密码或密钥。

本地文件不等于本地推理。敏感资料需要实际可用的本地模型与能力部署；
使用云模型前按照资料授权提示确认传输范围。私有模型服务按当前权益开通。
