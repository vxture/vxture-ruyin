# P26 平台衔接准备

2026-11-22，只读核验与本仓待办。本页记录当前发现及验收问题，不定义新的跨仓接口标准。
正式接口仍需维护平台唯一接入通则及对应实现。本批不修改或部署平台代码。

## 架构边界

RUYIN 是公共桌面客户端和本地任务宿主，不持有平台服务密钥。
Accounts 提供身份，平台负责组织、工作区、订阅与权益；RUYIN 展示并消费结果。
智能体调用 Atlas，不新增经 RUYIN 中转的推理服务。
Runos 云执行与本地受控能力安装分别验证；看到能力目录不等于能执行。

## 界面判断原则

“已订阅”表示权益；“已安装”表示本机存在可用包；“在线”表示权威目录提供浏览器入口。
同一产品可同时提供在线与桌面入口。纯在线产品不显示“未安装”。
离线时可展示注明来源的最后有效目录，不能据此授予已撤销的权益。
登录后刷新目录和切换工作区后的范围检查需要与独立后端契约一起落实。
